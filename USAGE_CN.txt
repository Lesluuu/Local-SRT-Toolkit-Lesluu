  这个工具能做什么?
  ─────────────────
  1. 转录: 把视频里的对话转成字幕文件 (SRT)
     - 支持日语/中文/英语/韩语等
     - 尽量保留哭/笑/叹气等语气词
     - 有 NVIDIA 显卡会自动用 GPU 加速, 没有就用 CPU

  2. 翻译: 把日文/英文/韩文的 SRT 字幕翻译成中文 SRT
     - 翻译后的文件保存在你指定的另一个文件夹, 不会覆盖原文件

  系统要求
  ─────────────────
  - Windows 10 / 11 (64位)
  - Python 3.10 / 3.11 / 3.12
    下载地址: https://www.python.org/downloads/
    ★ 安装时务必勾选 "Add Python to PATH" ★
  - 硬盘空间: 至少 10GB (依赖包 ~2GB + 模型 ~5GB + 视频)
  - 推荐: NVIDIA 显卡 (GTX 1060 6GB 以上), 没有也能用 CPU 但慢很多
  - 网络: 首次使用需要联网下载模型, 之后永久离线运行

  ⚠️  解压 ZIP 后的第一步 (非常重要, 否则会闪退!)
  ───────────────────────────────────────────────
  从 GitHub 下载 ZIP 解压后, Windows 会默认把里面的脚本标记为
  "来自互联网, 不安全", 直接双击会闪退或被拦截. 请用以下任一种
  方法解除:

    方法 A (推荐, 一次搞定):
      在解压之前, 右键你下载的那个 ZIP 文件 → 【属性】→
      在【常规】选项卡最下方, 如果看到
      "安全: 此文件来自其他计算机, 可能被阻止以帮助保护此计算机。"
      → 把右边的 【☑ 解除阻止】勾上 → 点【确定】→ 再解压 ZIP.

    方法 B (已解压过了怎么办):
      直接进入解压后的文件夹, 双击 【0_RUN_FIRST.bat】.
      这个文件内部已经包含了"自动解除阻止"的步骤, 会帮你
      把所有脚本自动解锁. 即使闪退了一次, 解锁后第二次打开
      就正常了.

  使用步骤 (三步, 全程不用命令行)
  ───────────────────────────────

  第 0 步: 确认已安装 Python 3.10 / 3.11 / 3.12
    没装先去 https://www.python.org/downloads/ 下载安装,
    ★ 安装时务必勾选 "Add Python to PATH" ★
    (64 位 Windows, 只支持 64 位 Python)

  第 1 步 ★ 唯一入口: 双击 【0_RUN_FIRST.bat】
    它会自动帮你做以下四件事, 你什么都不用管, 看屏幕提示:
    [1/4] 自动解除 Windows 的阻止标记 (修复 ZIP 下载闪退问题)
    [2/4] 检测 Python (没装好会告诉你怎么安装)
    [3/4] 检查并安装依赖 (首次约 2-5 分钟, 从清华/阿里云镜像下载,
          两个镜像自动切换)
    [4/4] 进入启动中心菜单

  第 2 步: 在启动中心菜单里输入数字回车
    1 = 开始转录视频生成字幕
    2 = 开始翻译字幕 → 中文
    3 = 重新安装 / 修复依赖
    4 = 打开本说明

  工作流程 (功能菜单里具体怎么操作)
  ────────────────────────────────

  ▶ 菜单选 1 (转录视频, 生成字幕)
    1. 首次使用会自动从国内镜像下载转录模型 (~1.6GB), 需联网
    2. 输入语言代码 (默认 ja=日语, 直接回车)
    3. 输入精度模式 (默认 high=高精度, 直接回车)
    4. 弹出文件夹选择框 → 选视频所在文件夹
       ★ 没看到弹窗? 按 Alt+Tab 切窗口 ★
    5. 输入 all 或视频编号, 开始转录
    6. SRT 生成在视频同目录下

  ▶ 菜单选 2 (翻译字幕 → 中文)
    1. 首次使用会自动从国内镜像下载翻译模型 (~3GB), 需联网
    2. 弹出第一个选框 → 选【SRT 源文件夹】
       ★ 没看到弹窗? 按 Alt+Tab 切窗口 ★
    3. 弹出第二个选框 → 选【输出文件夹】
       ★ 必须和源文件夹不同, 绝不会覆盖原文件 ★
    4. 输入 all 或编号, 开始翻译
    5. 中文 SRT 在输出文件夹里

  ★ 重要: 首次使用会自动下载模型 ★
  ────────────────────────────────
  转录工具和翻译工具第一次运行时, 都会自动从国内镜像
  (hf-mirror.com) 下载所需的大模型:

    转录模型: whisper-large-v3-turbo (CTranslate2格式) ~1.6GB
    翻译模型: Facebook NLLB-200 distilled-600M         ~3GB

  下载完成后永久保存在本地, 以后断网也能用。
  下载速度取决于你的网络, 一般 5-30 分钟。

  模型文件存放位置:
    转录模型 → 项目目录下的 fw_model/ 或 HF 缓存目录
    翻译模型 → 项目目录下的 mt_models/

  常见问题
  ─────────

  Q: 双击 bat 闪退 / 提示找不到 Python?
  A: 没装 Python 或没勾 "Add to PATH"。去 python.org 重装,
     勾选 "Add Python to PATH", 然后重新双击 0_RUN_FIRST.bat

  Q: 安装依赖失败 / pip 下载慢?
  A: 确保网络正常, install.bat 已经用了清华镜像。
     如果还是慢, 手动换阿里云镜像:
     venv\Scripts\pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/

  Q: 下载模型卡住 / 超时?
  A: 模型从 hf-mirror.com 国内镜像下载, 正常需要 5-30 分钟。
     如果卡住超过 1 小时, 关掉窗口重新运行, 会断点续传。

  Q: 转录很慢?
  A: 没有 NVIDIA 显卡时会用 CPU, 速度约为 GPU 的 1/5。
     有 NVIDIA 显卡但仍然慢, 检查驱动是否最新。

  Q: 弹出文件夹选择框看不到?
  A: 按 Alt+Tab 切换窗口, 对话框可能被命令行窗口挡住了。

  Q: 输入 5! (带感叹号) 没反应?
  A: 已修复全角字符问题。中文输入法下直接输 5！ 也能识别。

  Q: 翻译结果有日文碎片 / 不通顺?
  A: 转录精度不够会导致翻译质量下降。建议:
     1. 转录时选 high 高精度模式
     2. 确认视频音频质量清晰

  Q: 想重新转录/翻译某个文件?
  A: 输入编号时加感叹号, 如 5! 或 3!, 会强制覆盖已有结果。

  文件说明
  ─────────
  0_RUN_FIRST.bat      → 首次使用前运行, 自动安装+启动入口
  install.bat          → 安装依赖 (由 0_RUN_FIRST.bat 自动调用)
  start_transcribe.bat  → 启动字幕转录
  start_translate.bat   → 启动字幕翻译
  transcribe.py         → 转录核心代码
  translate.py          → 翻译核心代码
  requirements.txt      → 依赖包列表
  venv/                 → 虚拟环境 (安装后自动生成, 不上传 GitHub)
  fw_model/             → 转录模型 (首次运行自动下载, 不上传 GitHub)
  mt_models/            → 翻译模型 (首次运行自动下载, 不上传 GitHub)
